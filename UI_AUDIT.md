## Исправления

- Адаптивные размеры заголовков и статистики: главная, шесть услуг, обучение, юридические страницы. Длинные слова остаются внутри контейнеров; суммы и скидки в первом экране услуг не разрываются внутри значения.
- Перестроены тесные сетки услуг, контактов и обучения; исправлены подписи фотографий, фильтры портфолио и блок записи. Сохранены существующие контент, изображения и визуальный стиль.
- Высота фиксированной шапки согласована с отступом страницы и мобильным меню. Меню помещается на коротких экранах; прокручивается его содержимое, основные действия остаются доступны.
- Cookie-баннер, приветственное окно и мессенджеры больше не конкурируют за взаимодействие. Приветственное окно ждёт решения по cookie и закрытия меню, использует нативный modal dialog, ограниченную высоту и внутреннюю прокрутку.
- Исправлены возврат и удержание фокуса, Escape, блокировка фоновых элементов, размеры основных touch-кнопок и состояния `aria-expanded`/`aria-pressed`.
- FAQ показывает длинные ответы без ограничения высотой 200px. Карточка отзывов сохраняет высоту при переключении; автопрокрутка учитывает reduced motion, взаимодействие пользователя и скрытую вкладку.
- Повышен контраст вторичного текста, розовых акцентов и градиентных кнопок. Сохранена розовая палитра сайта.
- Убрано обещание обратного звонка по оставленному номеру из блока без формы сбора номера.

Использованы профильные навыки `frontend-design` и `accessibility-compliance-accessibility-audit`: сохранение характера существующего дизайна, визуальная проверка, контраст, клавиатура и reduced motion. Для документации использован Context7 MCP, для браузерной проверки — Playwright MCP и локальный Playwright.

## Покрытие

17 маршрутов: главная, 6 услуг, обучение, список блога, 6 статей, privacy и terms.

27 ширин: 320, 360, 375, 390, 412, 480, 639, 640, 641, 767, 768, 769, 820, 1023, 1024, 1025, 1100, 1279, 1280, 1281, 1366, 1440, 1535, 1536, 1537, 1920 и 2560px.

Геометрический аудит измеряет текстовые Range-прямоугольники, выход за границы блока/страницы, пересечения текста, HTTP-ошибки и pageerror. Обязательна фактическая загрузка Unbounded; результаты с запасным шрифтом не принимаются. Основной обход выполняется при высоте 900px. Отдельные тесты меню используют 320×480, 640×360, 820×600 и 1023×768.

Проверки axe на главной, обучении, privacy, блоге и перманентном макияже проверяют отсутствие serious/critical нарушений WCAG A/AA. Это не заменяет полноценную ручную сертификацию доступности.

## Воспроизведение

Обычная сборка при остановленном dev-сервере: `npm run build`.

Если dev-сервер уже использует `.nuxt`, можно собрать в отдельный каталог без изменения настроек приложения:

```powershell
$env:NODE_ENV='production'
node --input-type=module -e "import { loadNuxt, build } from 'nuxt'; const app = await loadNuxt({cwd:process.cwd(), overrides:{dev:false, buildDir:'artifacts/ui-audit/nuxt-build'}}); try {await build(app)} finally {await app.close()}"
```

Запустить собранный сайт в отдельном терминале:

```powershell
$env:PORT='3105'
$env:HOST='127.0.0.1'
node .output/server/index.mjs
```

Проверки:

```powershell
npx vue-tsc --noEmit
$env:PLAYWRIGHT_NO_WEBSERVER='1'
npx playwright test --workers=3
node tests/ui/audit-layout.cjs final-chromium
$env:AUDIT_BROWSER='firefox'
node tests/ui/audit-layout.cjs final-firefox
$env:AUDIT_BROWSER='webkit'
node tests/ui/audit-layout.cjs final-webkit
node tests/ui/capture-ui.cjs
git diff --check
```

Для повторного Chromium-аудита после других движков установите `$env:AUDIT_BROWSER='chromium'`. Для аудита доступны `AUDIT_WIDTHS` и `AUDIT_URL`; скриншоты отделены от измерений в `capture-ui.cjs`. Нужен доступ к Google Fonts. Яндекс Метрика и встроенная карта в тестах замещаются, чтобы внешние сервисы не влияли на измерения и не получали тестовые события.

Артефакты (не включены в Git):

- `artifacts/ui-audit/layout-final-{chromium,firefox,webkit}/report.json` — измерения.
- `artifacts/ui-audit/visual-final/` — реальные viewport-скриншоты; они не скрывают фиксированные элементы интерфейса.
- `playwright-report/index.html` — результаты браузерных тестов.

## Границы проверки

Работа выполнена локально; публикация, коммит и push не выполнялись. Предшествующие пользовательские изменения и перестановки изображений сохранены. Нативный Safari/iOS и физические устройства не проверялись: WebKit — автоматизированный движок Playwright, а не замена таким проверкам. Автоматическая геометрия и выборочные скриншоты не являются гарантией отсутствия всех возможных визуальных дефектов.

Сборка сохраняет предупреждения зависимостей Nuxt о cache-driver и устаревшем exports mapping; они не блокируют полученную production-сборку.
